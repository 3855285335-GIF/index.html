# Chatter 全部限制清单（build 3.8，2026-11-05 整理）

标记说明：
- **【官网】** 2026-11-05 在官网核实过，后面附来源。
- **【自己定】** Chatter 代码里自己设定的，想改随时可以改。
- **【系统】** 手机或浏览器的限制，Chatter 改不了，但写了绕开的办法。
- **【估算】** 是按官网数字换算出来的，不是官网原话。

## 一、免费服务的额度

### Supabase 免费版（数据库、文件、登录、实时通道）【官网】

| 项目 | 免费额度 | 对 Chatter 意味着什么 |
|---|---|---|
| 数据库大小 | 每个项目 500 MB | 文字消息很小，一时用不完【估算：一条文字消息连同索引大约几百字节，能存一百万条以上】 |
| 文件存储 | 1 GB | 图片、语音、视频、文件、表情、头像**全部共用，两个人也共用**。【估算】大约能放 20 个 50 MB 的视频，或 300 张左右 3 MB 的照片。满了可以在“我 → 存储空间”清理旧文件 |
| 流量（Egress，从 Supabase 流出的数据） | 每月 5 GB，另有 5 GB 缓存流量（Cached Egress） | 看图、看视频、打开文件、加载表情都算流量。【估算】一个 50 MB 的视频，对方完整看一遍就用掉 50 MB |
| 单个文件上传 | 最大 50 MB | 所以 Chatter 的图片、视频、文件单个上限都是 50 MB |
| 月活跃用户 | 50,000 | 用不完 |
| 实时通道同时连接 | 200 个 | 用不完 |
| 实时消息 | 每月 200 万条；每秒 100 条 | 用不完（国内模式不走实时通道，走普通请求） |
| 实时广播单条大小 | 256 KB | Chatter 每条信号只有几百字节 |
| 不活跃暂停 | 7 天没有活动会暂停 | 已经用私有仓库的定时任务每天“签到”一次（保活） |
| 活跃项目数 | 最多 2 个 | — |
| 自动备份 | 免费版没有 | 数据丢了找不回来；重要的聊天记录建议自己截图或另存 |
| 日志保留 | 1 天 | — |

来源：[Supabase 价格页](https://supabase.com/pricing)、[文件大小限制](https://supabase.com/docs/guides/storage/uploads/file-limits)（原话：Free 项目不能超过 50 MB）、[实时通道限制](https://supabase.com/docs/guides/realtime/limits)。

### 通话中转（只在两台手机不能直连时才用，直连不花额度）【官网】

| 服务 | 免费额度 | 说明 |
|---|---|---|
| ExpressTURN（主力） | 每月 1000 GB | 免费版只有 3478 端口的 UDP 和 TCP；国内不开 VPN 时用户实测 TCP 通、UDP 不通 |
| Metered（备用） | 方案名就叫“Free: 500 MB trial”，每月 500 MB（上传加下载合计） | 超出后会怎样官网没写；只在 ExpressTURN 连不上时才会用到 |

【估算】“清晰”画质视频约 2.5 Mbps，走中转时单方向每小时约 1.1 GB：ExpressTURN 的 1000 GB 很够用；Metered 的 500 MB 只够十几分钟视频通话。

来源：[ExpressTURN 官网](https://expressturn.com/)、[Metered 价格页](https://metered.ca/pricing)。

### GitHub【官网】

| 项目 | 限制 | 说明 |
|---|---|---|
| 网站（GitHub Pages）大小 | 最大 1 GB | Chatter 整个网页约 224 KB |
| 网站流量 | 每月 100 GB（软上限，不是硬性切断） | 【估算】够打开几十万次 |
| 发布一次 | 超过 10 分钟会失败 | Chatter 发布一般不到 1 分钟 |
| 构建次数 | 每小时 10 次（软上限） | 所以每次改动攒在一起只发布一次 |
| 保活定时任务（私有仓库） | GitHub 免费账户每月含 12 美元的运行额度；2 核 Linux 每分钟 0.006 美元 | 【估算】保活每天运行约 1 分钟，一个月约 0.2 美元，远低于额度 |
| 为什么放私有仓库 | 公开仓库 60 天没有任何活动，定时任务会被自动停用 | 私有仓库没有这条规定 |

来源：[GitHub Pages 限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)、[GitHub Actions 计费](https://docs.github.com/en/billing/concepts/product-billing/github-actions)、[定时任务自动停用](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/disable-and-enable-workflows)。

## 二、Chatter 自己定的限制【自己定】

### 消息
| 项目 | 限制 |
|---|---|
| 文字 | 每条最多 5000 字（数据库也会拦） |
| 一次选几个 | 图片、视频、文件合计一次最多 9 个 |
| 图片 | 单张最大 50 MB（没运行 setup-v6.sql 之前是 20 MB），**原图上传，不压缩** |
| 视频 | 单个最大 50 MB，**原文件上传，不压缩**，显示时长 |
| 文件 | 单个最大 50 MB，任何类型；网页类文件（html 等）按纯文本保存，打开时不会被当成网页运行 |
| 语音 | 按住说话最长 60 秒（到 60 秒自动发出），短于 0.8 秒不发；格式是 12 kHz 单声道 WAV（所有手机都能播），60 秒约 1.4 MB |
| 撤回 | 发出后 2 分钟内（文字、图片、语音、表情、视频、文件都可以） |
| 删除消息 | 只删自己这边；这台手机最多记住最近 3000 条删除记录，更早删掉的在很久以后翻旧记录时可能重新出现 |
| 转发 | 文字、图片、语音、表情、视频、文件都能转发；转发出去的和原消息用同一个文件，原发送人在“存储空间”里清理后，转发出去的也会看不到 |
| 聊天记录 | 每次加载 40 条，往上滑再加载 40 条；这台手机缓存最近 12 个聊天各 40 条（用来秒开） |
| 搜索聊天记录 | 只搜文字消息；最多找 80 条，显示 50 条 |
| 找好友 | 最多显示 20 个结果 |
| 发送失败 | 网络恢复后自动重发，最多 8 次；也可以点消息左边的 ! 重试 |
| 置顶、免打扰、草稿 | 只记在这台手机上，换手机或退出登录要重新设 |

### 表情包
| 项目 | 限制 |
|---|---|
| 我的表情 | 每人最多 500 个（数据库也会拦） |
| 单个表情 | 最大 10 MB，原图上传，GIF 动图也行 |
| 搜索关键词 | 每个表情最多 60 个字，多个关键词用空格隔开 |
| 最近使用 | 记住最近 16 个 |
| 联想表情 | 输入框里只有 1–6 个字、并且刚好是关键词时才冒出来，最多 6 个 |
| 表情库 | 316 个 emoji、40 个文字贴纸（自己画的）、46 个大表情。文字贴纸发出去只有几个字节，不占存储空间 |
| 流量 | “我的”页第一次打开会下载表情原图（只下载看得到的那几个），之后手机会缓存 |

### 账号
| 项目 | 限制 |
|---|---|
| 账号 | 3–20 位，只能用英文小写、数字、_、- |
| 密码 | 至少 6 位 |
| 昵称 | 最多 20 个字 |
| 头像 | 裁成正方形 400×400 的 JPEG（头像是唯一会被压缩的图片，为了加载快） |

### 通话
| 项目 | 限制 |
|---|---|
| 呼叫 | 45 秒没人接自动挂断；对方那边的来电铃声响 40 秒 |
| 接通 | 接听后 25 秒还连不上就断开（多半是网络受限） |
| 画质 | 超清 1080p 约 4 Mbps、清晰 720p 约 2.5 Mbps（默认）、流畅 480p 约 1 Mbps |
| 中转省流量 | 默认关。打开后只在走中转时生效：视频约 300 kbps、分辨率减半，语音约 24 kbps |
| 直连 / 中转 | 每 4 秒检查一次 |

### 国内模式（不开 VPN 时自动启用）
| 项目 | 限制 |
|---|---|
| 收消息 | 服务器最多等 2.5 秒；一次请求 10 秒没回就重发；一次最多取 100 条 |
| 通话信号 | 1 分钟内有效；10 分钟没被取走自动清理；单条最大 60000 字节 |
| 在线状态 | 每 40 秒报到一次，75 秒内报到过算在线；上线、下线、切后台时立即推送 |
| 正在输入 | 最多 3 秒发一次，对方显示 4.5 秒 |
| 存储空间统计 | 最多统计 10000 个文件 |

## 三、手机系统的限制【系统】

| 情况 | 原因 | 办法 |
|---|---|---|
| iPhone 从“照片图库”选视频时，会先显示“正在压缩视频” | iOS 自己在上传前压缩，网页拦不住（[Apple 开发者论坛](https://developer.apple.com/forums/thread/731042)、[说明文章](https://help.heymarvelous.com/en/articles/4121947-why-does-the-iphone-automatically-compress-my-video-files)） | 想发原画质：在“照片”里打开视频 → 分享 → **存储到“文件”**；然后在 Chatter 点图片按钮选 **选取文件**，或点右上角 ⋯ → **发送文件**，选刚才存的视频 |
| iPhone 录的视频是 MOV（多为 HEVC 编码） | 苹果的格式 | iPhone、Mac 上能正常播；部分安卓、Windows 浏览器可能放不了（未逐一测试），可以“保存到手机”后用别的播放器看 |
| 网页不能直接把图片写进相册 | 浏览器的安全限制 | 点“保存到手机”后会弹出系统分享面板，选 **存储图像** / **存储视频** / **存储到“文件”** |
| App 关掉或在后台久了收不到提醒 | 网页版没有推送服务 | 要另外搭推送（见功能建议） |

## 四、只在电脑上模拟测过、需要真机确认的

- iPhone 上发视频、看视频（播放、全屏、声音）。
- “保存到手机”弹出的系统分享面板，以及存进相册。
- 从“选取文件”发原画质视频、发 PDF 等文件，以及点开预览。
- 国内网络下上传 50 MB 大文件的速度和成功率。
- 表情面板、长按菜单、联想表情在 iPhone 上的手感。
