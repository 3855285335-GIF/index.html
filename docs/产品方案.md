# Chatter 产品方案和执行流程

> 2026-11-21 写（Claude）。按用户要求：“从功能全部要求、具体实行方案、别人做不到的、每一个细节体验感，来当作具体流程”。
> 以后每做一件事，按这份的顺序来，做完在第 9 节打勾。两个 AI（Claude、ChatGPT）都按这份做。
> 标“没核实”的数字和说法，做之前必须先查官网或实测。

---

## 0. 总原则（每个功能都要过这几条）

1. **全部在 Chatter 里完成**，不跳到别的软件、不跳到手机自带浏览器。只有用户自己点“在浏览器打开”时才出去。
2. **简单**：一屏只做一件事，按钮少、字大，不要花里胡哨的装饰和标语。
3. **国内用国内普通网络能用**，网络出口在境外也能用（自动换能用的服务，并且说清楚为什么）。
4. **只用免费服务**；额度从一开始就省着用（缓存、小图、合并请求）。
5. **画质优先**：图片、视频默认原图、不压缩；不经同意不降低通话质量。
6. **跟随“我”里的主题和字体**，浅色、深色都要好看。
7. **不默认所有人都用苹果**：文字里不写 Safari、iPhone，安卓和电脑一样能用。
8. **出错要说人话**：说清是哪里出了问题、用户能做什么，给对应的按钮（重试、换一个、看原因）。不能出现英文代码、空白页、转圈不停。
9. **交付前**：自动检查全部通过，自己把使用过程走一遍，列出“只在电脑上模拟过、要真机试”的清单。

## 1. 网络——所有功能的地基

**现状**（11-21 实测）：
- 天地图只让国内网络用：东京、美国的服务器一律“访问被拦截”。手机网络出口在境外时出口在国外，天地图也会拒绝。11-21 用户截图：换回国内网络，天地图的街道图、搜地点都正常。
- Supabase 的实时通道在国内用国内普通网络时常连不上，所以 App 有轮询兜底（国内模式）。
- B 站、Audius、路线服务、Esri、Photon 在国内用国内普通网络都能用（用户实测）。

**做法**：
1. 每个依赖外部服务的功能都要有第二家备用，出错时自动换，并告诉用户换了什么。导航已经这样做了：天地图不行换 Esri，搜地点不行换 Photon。
2. **新加一个“网络体检”页**，放在“我”里：一次测完 Chatter 用到的所有服务（聊天服务器、实时通道、搜索、天地图、音乐、B 站、路线），每项显示通不通、多快。不通的直接说原因，比如“网络出口在境外时天地图会拒绝”。
3. 能猜出“网络出口在境外”的情况（天地图不通但国外服务通）就直接提示：“你可能网络出口在境外，天地图要国内网络。换回国内网络，或者让 tianditu.gov.cn 走国内网络”。
4. 天地图恢复（换回国内网络）后**自动换回**，不用重开。11-21 已做。

**别人做不到的**：一般 App 出错只说“网络错误”；Chatter 说清是哪一家不通、为什么、怎么办，并自动换备用。

**验收（真机）**：走境外网络、国内网络、飞行模式各打开一次导航、音乐、搜索，看提示对不对、会不会自动恢复。

## 2. 聊天

**要求**：消息顺序稳定、多设备同步、撤回、编辑、引用、语音、视频、文件、群聊、推送、退出其他设备、发图默认原图。

**现状**：上面这些都已经做了（GPT 11-19 修了一批稳定性问题，Claude 修了消息预览等）。

**还要做的**：
1. **推送真机验证**：iPhone 要把 Chatter 添加到主屏幕后才能收推送（苹果的规定，iOS 16.4 起，没核实具体小版本）。“我”里加一个“测试推送”按钮，点了 5 秒后给自己推一条。
2. **发送状态更清楚**：每条消息右下角固定显示“发送中 / 已发送 / 失败（点了重发）”。断网时自动排队，联网后按顺序发出。
3. **大文件**：选文件时先告诉用户大小和免费额度剩多少（Supabase 免费版文件空间 1 GB，已核实），超出时提示删旧附件（“管理已发送附件”已有）。
4. **通话**：中转服务器名单在数据库里。真机测一次国内用国内普通网络时的视频通话，看能不能接通、清不清楚。

**细节体验**：长按消息出菜单（复制、引用、转发、撤回、编辑、删除、多选）；引用点了跳到原消息并闪一下；图片点开能左右滑、双指放大、长按保存；语音消息放的时候别的声音（音乐）自动停；链接在 App 里打开；位置消息（导航发的）点了直接在导航里打开。

**别人做不到的**：聊天里的链接、位置、歌都能在 Chatter 里直接打开、直接听、直接导航；搜索结果、网页、歌一键发给好友。

## 3. 朋友圈

**要求**：四种可见范围（公开 / 私密 / 部分可见 / 不给谁看），发出去还能改；不让对方看我的、不看对方的；不是好友只看得到赞、看不到评论（像微信）；名单只有作者看得到。

**现状**：都已做，数据库权限已上线（11-19）。

**还要做的**：
1. 私密照片（GPT 的 PR #4、#5）：先让照片在手机里缓存（不然每次重新下载、费流量、没网看不了），再改线上存储权限。
2. 发朋友圈时视频不压缩，封面自动截第一帧。

## 4. 浏览器 / 搜索

**要求**：①什么都能搜到，比普通浏览器限制少得多；②简单。在 App 里打开，不跳到自带浏览器。外文自动翻译。打不开要说清原因。仿冒网站红色提醒。

**现状**：搜索（Exa + Tavily + 深挖：维基百科、互联网档案馆、论文、GitHub、Hacker News）、翻译、阅读模式、窗口、前进后退、收藏、历史都有了。
**11-21 用户反馈的问题**：
- 点一些网址会跳到自带浏览器。原因：网页里“在新窗口打开”的链接，网页框允许它开新窗口，iPhone 桌面版就跳出去了。11-21 已改成不许开新窗口。
  - 副作用：这种链接点了会没反应。网页 App 拦不住、也看不到这种链接的地址。所以要配合第 2 条。
- 好多网站显示“不支持查看”。原因：有的网站发现自己被放在别的 App 里，就不给看（微信公众号、抖音、小红书这类常见，具体是哪些要你发几个网址给我）。

**11-21 用户：“不要阅读模式了”（原网站变成文字就看不懂）；全部都能打开，不跳到别的软件。**

**做法**：
1. 已做（20261121d）：不再自动换成文字版。不让嵌的网站给说明卡片，按钮是“用手机浏览器打开”（写明会离开 Chatter，只在你点时）、“看存档”、“返回”。文字版只在你自己点“翻成中文看”时出现。
2. **要真正做到“全部都能在 App 里打开”，只能做成装在手机上的 Chatter App**（第 8 节）。网页做的 App，碰到网站自己设了“不让别的 App 显示”，任何写法都打不开原网页。唯一的绕法是让我们的服务器替手机去取整个网页再转给手机，这条我不做（等于做了绕过网络限制的工具）。

**别人做不到的**：自己的排序（官网第一、营销号隐藏、置顶、不看的网站）；仿冒网址红色提醒；打不开时说清原因并给存档；外文整篇自动翻译；深挖一键搜档案馆、论文、代码；浏览记录不出手机；看到的东西一键发给好友。

**做不到的（网页 App 的限制，要说清楚）**：网站禁止被嵌入的，原网页没法原样显示，只能用阅读模式。只有原生 App 的内置浏览器能做到（微信就是）：安卓可以免费做（第 8 节），iPhone 要每年 99 美元（苹果官网，已核实）。

**验收（真机）**：你把最近看不了的网址发我；每个都在 App 里打开一次，看是原网页、阅读模式还是官方播放器，有没有跳出去。

## 5. 音乐

**要求**：通过自己的搜索找免费、公开的音频；中文歌要有。

**现状**：Audius（热门、搜歌、正在播放、迷你条、锁屏控制）+ B 站（11-21 上线：搜中文默认先看 B 站，用 B 站官方播放器在 App 里放）。

**还要做的**：
1. **歌单 + 跨设备同步**：现在“我喜欢”只存在这台手机。加一张表（要你运行一次 SQL），Audius、B 站的歌都能存进歌单，换手机也在。
2. **一起听**：在聊天里点“一起听”，两边放同一首。Audius 能对准到秒；B 站的只能从同一个时间点开始放（B 站播放器网址带开始时间），之后不能再对准，要说清楚。
3. **网易云官方外链播放器**作第三栏：只有版权方允许的歌能放，大部分流行歌放不了，要说清楚。
4. 定时停止（15 / 30 / 60 分钟）。

**细节体验**：B 站的歌要在画面里点一下才开始放（B 站播放器的规定），第一次放时用一个箭头指给用户看；B 站的歌能停不能暂停（别人的播放器拦不住），按钮就写“停止”；来电、录语音时音乐自动停。

**做不到的**：B 站的歌锁屏后能不能接着放、锁屏界面能不能控制，要真机试（网页框里的视频很可能不行）。安卓原生壳可以解决。

## 6. 导航

**要求**：自己的界面、卫星图、在 App 里导航、不跳别的软件。

**现状**（11-21 重写版）：全屏地图；天地图街道图和卫星图；搜地点、附近；长按选点；驾车 / 骑行 / 步行路线；跟着走的导航（转向提示、语音、走错重算、到达、屏幕常亮）；和好友一起去；发位置；地图服务检查。
**11-21 用户反馈**：
- 网络出口在境外时天地图不给图。已改提示，换回国内网络自动换回。
- “都是很久以前的，最近出现的都没有”：天地图和开源地图的数据更新慢，新开的店、新修的路常常没有。

**做法**：
0. **我之前说错了 / 做错了**：一开始选天地图时，我只说了“免费、国内能连”，没告诉你它的卫星图和地点数据比高德旧很多。你实测卫星图是十几年前的学校，搜出来还写在建。这种选择本该先让你选。
1. **数据换成高德**（国内数据最新，有实时路况）：搜地点、查地址、驾车 / 步行 / 骑行 / 公交路线都用高德的接口。
   - 要你免费注册一个高德开发者账号，拿一个 Key（要手机号实名）。个人开发者的免费额度官网我这边打不开，**没核实**，注册后在控制台能看到。
   - 高德的坐标和手机定位差几百米（国家规定的加偏，叫 GCJ-02）。App 里统一换算（公开的换算公式，误差 1–2 米）。地图仍用天地图（和手机定位一致），所以不用换底图。
   - 高德不行时自动换回天地图 / 开源数据，并说明。
   - 如果天地图的底图本身也旧（新修的路没有），再加“高德底图”可选（高德的图块不是公开给别人用的接口，可能被限制，要说清楚）。
2. **公交、地铁路线**：高德有公交路线接口，显示换乘、步行段、几站、末班车。
3. **路况**：驾车时间用高德的实时路况估算。
4. 收藏的地点（家、公司）跨设备同步（和歌单一起建表）。

**别人做不到的**：和好友一起去（互相看到位置、会合点、30 分钟后自动删、位置不进数据库日志、不进备份）；在聊天里一键发位置、邀请；没有广告；“今天去哪”直接导航过去。

**做不到的**：锁屏或切到别的 App 后，网页拿不到位置，导航会暂停。这是网页的限制，屏幕常亮能缓解；安卓原生壳能解决。

**验收（真机）**：国内网络；搜一个新开的店（看找不找得到）；驾车、步行各导航一小段；网络出口在境外再试一次（看提示和自动切换）。

## 7. 今天去哪（还没开始）

**要求**：挑废弃的、小众的地方。

**做法**：
1. 数据：开源地图里标了“废弃 / 遗址 / 旧址 / 废墟 / 老厂房”的地点（OpenStreetMap 的 abandoned、ruins、historic 标签），加上高德的“风景名胜 / 古迹”类里人少的。国内开源数据少，**要先实测附近能找到多少**，没核实。
2. 每张卡片：名字、离你多远、一句介绍、照片（维基共享资源，有就显示）、“导航去”“叫上好友一起去”。
3. “换一个”随机下一个；能按距离（5 / 20 / 50 公里）和类型筛。
4. 安全提示：废弃地点可能有危险、禁止进入，卡片上提醒注意安全、遵守规定。

**别人做不到的**：专门挑小众、废弃的地方；一键叫好友、一起导航过去。

## 8. 以后：安卓原生壳、转发站

1. **装在手机上的 Chatter App**（11-21 起最要紧：你要的“全部都能打开、不跳到别的软件”只有这样能做到）：
   - 能做到的：所有网站在 App 里原样打开（不是文字版、不跳出去）；锁屏能继续导航、继续放歌；通知更稳。
   - 安卓：免费，GitHub 上打包，装一个文件就行。
   - iPhone：苹果开发者账号中国大陆 **¥688/年**（苹果官网已核实），不能用 Apple 账户余额付；能不能用支付宝 / 微信付，官网没写（没核实，注册时 App 里会显示）。不上架也能装到登记过的手机上（上限多少台没核实）。打包可以用 GitHub 提供的苹果电脑服务器，不用你有苹果电脑（没实测）。
   - **要你决定**：要不要花这个钱；身边用安卓的多不多。
2. **不买域名的转发站**：只转发 Chatter 自己的聊天服务器（不是绕过网络限制的工具、不是通用代理），让国内用国内普通网络时实时消息更稳。先用测试页在国内手机上实测几个免费平台能不能连，再决定用哪个。
