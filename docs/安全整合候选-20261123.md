- Vercel 自动分支预览不等于独立后端。候选 app.js 原本直连线上 Supabase；已在启动入口禁用非官方 `.vercel.app` 预览域的登录和收发入口，并添加自动检查；正式 `chatterapphtml.vercel.app`、GitHub Pages 及本地测试入口不受此门禁影响。正式网站若还有其他合法 Vercel 域名需另行核实。

## 可核查项（仅只读查询）

```sql
select p.proname,
       has_function_privilege('anon', p.oid, 'EXECUTE') as anon_can_execute,
       has_function_privilege('authenticated', p.oid, 'EXECUTE') as authenticated_can_execute
from pg_proc p join pg_namespace n on n.oid = p.pronamespace
where n.nspname='public' and p.proname in ('is_group_member','is_group_owner','send_group_msg','my_acc','keepalive')
order by p.proname;
```
